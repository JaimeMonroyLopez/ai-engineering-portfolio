# AI Engineering Portfolio

Hands-on projects from my AI Engineering training: from a single agent with tools to a team of agents running on a local model.

| # | Project | What it shows | Stack |
|---|---|---|---|
| 1 | [AI Agent with Tools](https://github.com/JaimeMonroyLopez/ai-tools-agent-langchain) | An agent that chooses between a calculator and search | LangChain · Gemini |
| 2 | [Research Agent with Memory](https://github.com/JaimeMonroyLopez/ai-research-agent-langchain) | Memory, prompt chaining and JSON output | LangChain · Wikipedia API |
| 3 | [Visual AI Workflow](https://github.com/JaimeMonroyLopez/ai-visual-workflow-langflow) | A no-code flow, called from Python | Langflow |
| 4 | [Multi-Agent Support Team](https://github.com/JaimeMonroyLopez/ai-multi-agent-support-autogen) | 3 agents that triage, research and answer support tickets | AutoGen · Ollama (local) |

## Learning path

1. **One agent + tools**: how an AI decides which tool to use.
2. **Memory + structured output**: remembering context and returning data apps can use.
3. **Visual workflows**: building the same ideas without code.
4. **Multi-agent systems**: several specialized agents working as a team, 100% local.
